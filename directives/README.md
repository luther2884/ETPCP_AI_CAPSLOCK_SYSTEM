# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Structure of a Directive
Each directive defined here should outline:
1. **Goal**: What needs to be accomplished.
2. **Inputs**: Parameters, files, or environment variables required.
3. **Execution Scripts**: Python scripts in `execution/` to run.
4. **Outputs**: Expected deliverables or artifacts.
5. **Edge Cases & Failure Handling**: What to do when errors occur.
